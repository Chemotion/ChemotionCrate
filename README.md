# ChemotionCrate

ChemotionCrate (the Python package `chemotion-crate`) exports collections from a [Chemotion ELN](https://chemotion.net) as `.eln` files: RO-Crate archives that follow [TheELNFileFormat](https://github.com/TheELNConsortium/TheELNFileFormat), so the data can be archived and opened by other tools. It reads the ELN only through its REST API, with [chemotion-api](https://github.com/Chemotion/ChemotionAPI).
